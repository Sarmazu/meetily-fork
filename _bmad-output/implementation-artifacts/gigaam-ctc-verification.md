# История 1.3 — проверка Rust CTC

Дата: 2026-10-30. Ветка сохранена: `fix/whisper-library-upgrade`.

## Реализовано

Новые Rust-модули `preprocess.rs`, `ctc.rs`, `segments.rs`: log-mel по закреплённому NumPy-эталону, CPU ONNX-сессия, проверка ABI/словаря/пакета, CTC-collapse и detokenization, ограниченное неперекрывающееся разбиение. Результат — штатный TranscriptResult, confidence=None, is_partial=false. Короткий вход и цифровая тишина пропускаются; NaN/Inf отклоняются.

Загрузчик не переработан: его проверка файлов только открыта в пределах crate для повторного использования. UI, настройки, провайдеры записи/импорта и существующие Whisper/Parakeet не менялись. Это ещё не подключение GigaAM к трём пользовательским сценариям.

Веса повторно не скачивались: отдельные per-model каталоги используют hardlinks проверенных файлов истории 1.1; тесты их не изменяют.

Установленная DLL закреплена SHA-256 текущего build/onnxruntime.rs; версия и файлы модели соответствуют истории 1.1.

## Завершающие проверки после ревью

Эквивалентность detokenization ограничена символами закреплённого словаря; универсальная совместимость Python/Rust Unicode-классов не заявляется.
