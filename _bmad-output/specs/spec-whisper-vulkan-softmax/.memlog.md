- (note) Meetily 0.4.1 использует whisper-rs 0.13.2 и whisper-rs-sys 0.11.1 с whisper.cpp 1.7.1; на проверенной Windows x64/Radeon 780M импорт синтетического английского WAV даёт «Продолжение следует…».
- (note) Полная контрольная сумма установленной large-v3-turbo совпала с официальной; CPU-тесты Windows 1.7.6 и exact-source 1.7.1 распознали английскую речь.
- (note) При отсутствующей attention mask C++ передаёт KY=0; исходный Vulkan softmax безусловно вычисляет rowx%KY. Дефект найден также в двух embedded SPIR-V модулях установленного executable.
- (note) Upstream #2596 описывает неверный результат Windows/Radeon 780M; исправление #2633 добавляет проверку KY>0 и уже merged upstream.
- (note) Причинный Windows Vulkan A/B: одинаковые библиотека/модель/202080 сэмплов/параметры/FP16; исходный шейдер выбирает ru и выдуманный текст, исправленный выбирает en и ожидаемую английскую речь; оба rc=0.
- (note) Одна строка shader source изменена; из 230 generated arrays изменились только два softmax-варианта и соответствующие длины, остальные 228 побайтно одинаковы.
- (note) Первый fixed запуск стенда был недействительным из-за старых констант длины shader arrays; он исключён, причинный результат получен после согласованной пересборки backend/header.
- (note) Отключение FP16, добавление 4 секунд тишины и тот же сигнал в WAV float32 не исправили результат рабочего Meetily; исходный copied WAV совпадает с тестовым.
- (note) До отключения FP16 после перезапуска live worker выдавал непустые результаты; смысл реальной речи не собирался. Первоначальное отсутствие live текста отдельно не воспроизведено.
