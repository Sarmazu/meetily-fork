# Подтверждённый дефект и границы задачи

Постановка подготовлена 2026-10-24 и согласована пользователем. 2026-10-29 пользователь выбрал обновление официальной библиотеки. Технический план одобрен, обновление реализовано в fix/whisper-library-upgrade. Windows-сборка и частичная нативная приёмка выполнены; окончательная приёмка отложена по решению пользователя 2026-10-30.

## Причина и provenance

До обновления `Cargo.lock` закреплял whisper-rs 0.13.2 / whisper-rs-sys 0.11.1; последний содержит whisper.cpp 1.7.1. Его `ggml_vk_soft_max` передаёт KY=0, когда отсутствует attention mask; shader выполняет безусловный `rowx % p.KY`. В проверенном установленном executable обнаружены оба softmax SPIR-V модуля с этой незащищённой операцией. Runtime test target — Windows x64, AMD Radeon 780M.

[Upstream issue #2596](https://github.com/ggml-org/whisper.cpp/issues/2596) описывает некорректное вычисление на Windows/Radeon 780M; [merged fix #2633](https://github.com/ggml-org/whisper.cpp/pull/2633) добавляет защиту:

```diff
- const uint rowy = rowx % p.KY;
+ const uint rowy = (p.KY > 0) ? rowx % p.KY : 0;
```

## Причинный эксперимент

Две отдельные Windows Vulkan-сборки exact-source 1.7.1: одна модель large-v3-turbo, один сигнал 202080 сэмплов/16 kHz, параметры Meetily, FP16 включён. Изменена одна строка shader source и соответствующие embedded arrays/размеры; 228 из 230 массивов шейдеров совпадают побайтно. Обе сборки размещают 1623.92 MB модели на Vulkan0.

| Вариант | Автоязык | Результат | rc | Время |
|---|---|---|---|---|
| Исходный shader | ru | «Субтитры сделал DimaTorzok» | 0 | 12.48 s |
| Исправленный shader | en | Английская тестовая речь, с обычной локальной ошибкой fox/facts | 0 | 8.10 s |

Это историческое сравнение с минимальным patch подтверждает причинность дефекта; оно не подтверждает работоспособность нового релиза. Время не является performance SLA. Первый fixed-запуск с неправильными длинами shader arrays был недействителен и исключён. Здесь сохранены только окончательные логи после согласованной пересборки backend/header.

## Дополнительные факты

- Установленная модель целиком совпала с официальной. Exact-source CPU 1.7.1 и Windows CPU 1.7.6 распознали английскую речь.
- Рабочий Meetily выдавал «Продолжение следует…» для исходного файла, его float32-варианта и варианта с 4 s тишины; copied WAV совпал с источником. Отключение FP16 не устранило ошибку.
- После перезапуска live worker ещё до отключения FP16 выдал непустые результаты. Их содержимое не собиралось. Первоначальное состояние «запись идёт без текста» отдельно не воспроизведено: не объявлять все исторические live-проблемы устранёнными без проверки приложения.
- Диагностический процесс имел только временный GGML_VK_DISABLE_F16=1; обычный запуск после завершения процесса снимает флаг. Исполняемый файл рабочей установки не менялся.

## Доказательства в этом каталоге

- `evidence/synthetic-en.wav` — synthetic PCM16 mono 16 kHz, 12.63 s; точный файл проведённых тестов.
- `evidence/win-vulkan-baseline.{stdout,stderr}.log` и `evidence/win-vulkan-fixed.{stdout,stderr}.log` — четыре финальных лога, личные пути заменены placeholders. Baseline stdout приведён из OEM к UTF-8 без изменения содержания.
- Исходные диагностические инструменты оставлены в `/tmp/meetily-whisper-diag`; это дополнительный временный контекст, не обязательная зависимость спецификации. Toolchain и executable не включены в репозиторий.

## Принятое техническое решение

Обновлять официальную библиотеку: целевой `whisper-rs =0.16.0`, `whisper-rs-sys 0.15.0`, bundled whisper.cpp 1.8.3. Эти версии закреплены Cargo; Windows-сборка, native numerical test и частичная нативная приёмка выполнены. Результаты и оставшиеся ограничения — в [handoff](../../implementation-artifacts/whisper-acceptance-handoff.md). Источники: [whisper-rs 0.16.0](https://docs.rs/crate/whisper-rs/0.16.0/source/), [sys 0.15.0](https://docs.rs/crate/whisper-rs-sys/0.15.0/source/). Актуальный repository библиотеки — Codeberg, старый GitHub repository архивирован.

Причина выбора — получение upstream-исправлений и отказ от сопровождения собственного fork/vendor. Предложенный ранее backport не выбран и не реализовывался; не добавлять workspace path override и локальный sys-пакет. Если обновление заблокировано конкретной несовместимостью, представить доказательства и отдельно согласовать изменение решения.

Обновить три target-specific объявления зависимости, сохранить нужные features и закрепить разрешённые версии в Cargo.lock. Внутренняя адаптация требуется в обоих методах WhisperEngine: `full_n_segments()` теперь возвращает `c_int`; текст/тайминги доступны через `get_segment`/`as_iter` и `WhisperSegment`. Не переносить старые `?` и `full_get_segment_*` механически. Проверить параметры контекста, токенов и ошибки нового API. Публичные Tauri-команды, события и форматы данных сохраняются.

Проверить, что релиз включает устранение диагностированного дефекта; поиск старой строки не заменяет native regression. Сохранить Vulkan, CPU, macOS Metal/CoreML и существующие CUDA/HIP/OpenBLAS/OpenMP feature mappings, Windows AVX2/portability hook. Новый релиз нативного backend может менять вычислительные результаты и сборочные требования: проверить их явно, не обещать сохранение всех старых параметров без проверки.

Исходные evidence-файлы и stable CAP-1 остаются без изменений. Build-план: [spec-whisper-library-upgrade.md](../../implementation-artifacts/spec-whisper-library-upgrade.md).

## Текущий процесс

2026-10-30 пользователь согласовал перенос оставшейся live-приёмки на общую тестовую сборку после будущих фич, чтобы сократить повторные тяжёлые сборки. Build остаётся `in-progress` с отложенной приёмкой; CAP-1 не закрыт. Критерии не ослаблены, исходные evidence и результаты сохранены. Новая спецификация сейчас не создаётся.

Рабочая ветка — `fix/whisper-library-upgrade`, без commit/push/PR. Рабочая установка не заменялась. [Сводка проверок и открытых пунктов](../../implementation-artifacts/whisper-acceptance-handoff.md) задаёт порядок возобновления; исторический backport A/B остаётся доказательством причины, а не выполненной приёмкой будущей общей сборки.
