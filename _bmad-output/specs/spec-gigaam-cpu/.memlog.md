- (decision) Технические правила: один каталог GigaAM владеет идентичностью и полным manifest пакета; загрузка во временный каталог, проверка SHA256 и размеров, публикация только полного пакета. Явная ошибка вместо перехода к Whisper. Нет бенчмарков; функциональная матрица 4x3, snapshot/race/download tests и Windows acceptance обязательны.
