## Preprocessing

Input is mono float32 waveform at 16000 Hz, PCM16 converted by `/32768` for the
fixture. Single-segment harness requires `320 <= N <= 400000`. Future adapter
must split longer inputs and define short-input handling before calling ONNX;
this story does not change application segmentation. No centering, padding,
resampling, amplitude normalization, pre-emphasis, dither, or feature
normalization is performed by this export's v3 feature extractor.

- FFT/window: 320 samples; hop: 160; periodic Hann `np.hanning(321)[:-1]`.
- Hann constants rounded to bfloat16 then widened to float32, as in the fixed
  reference, even though inference models are FP32.
- 64 triangular HTK mel filters, 161 FFT frequency bins, inclusive 0..8000 Hz,
  no mel normalization. HTK `2595*log10(1+f/700)`, inverse
  `700*(10**(m/2595)-1)`, 66 equally spaced mel points. Filter coefficients
  likewise rounded to bfloat16 then widened to float32. This rounding is material.
- Multiply each unpadded frame by window; rFFT, magnitude cast to float32 then
  squared, matrix multiply filterbank; clip `[1e-9,1e9]`; natural logarithm.
- Output float32 `[B,64,T]`; int64 feature lengths `(N-320)//160+1`.
- Reference harness runs the **pinned NumPy preprocessor implementation** directly,
  with constants generated by its pinned filterbank function and the explicit
  bfloat16 rounding from pinned `preprocessors/gigaam.py`. No approximation
  using Parakeet preprocessing or current upstream defaults is allowed.

though encoder has a symbolic batch dimension.

## CTC, RNNT and detokenization

CTC takes argmax over vocabulary; masks positions beyond valid encoded length,
removes blank and collapses **adjacent original frame** repetitions. A blank
between identical tokens allows two emitted tokens. No beam search or language
model. Never transfer Parakeet TDT rules.

RNNT greedy decoding starts per waveform with h/c float32 zeros `[1,1,320]`,
empty token sequence and t=0. First decoder input x=int64 `[[blank_id]]`;
subsequent calls use the last emitted token. Joint input is the encoder frame
`[1,768,1]` and transposed decoder output `[1,320,1]`. Argmax of squeezed joint
logits emits nonblank; only then commit candidate h/c. On blank advance t while
retaining the cached prediction (do not run the prediction network again until
a token is emitted). Maximum **3 nonblank emissions per encoder frame**;
after the third emission advance t and reset the emission counter. Blank also
advances t/reset counter; this export's `_decode` returns step=-1. Reset state
for each independent input segment, never share recurrent state across clips.

Vocabulary is UTF-8 `token integer-id` per line, with explicit `<blk>` blank.
Replace U+2581 in tokens with ASCII space; concatenate selected token strings.
Apply the exact pinned Python regex `r"\A\s|\s\B|(\s)\b"`, replacing a match
with one space iff capture group 1 exists, otherwise with the empty string.
This is the reference's spacing cleanup; do not substitute arbitrary trim,
Unicode normalization, case folding, punctuation rewriting or LLM correction.
`<unk>` exists at ID 0 for E2E models. Ordinary vocabulary has space at ID 0,
Russian а..я at 1..32 (without ё), blank at 33. E2E vocabularies are exported
token tables; no external SentencePiece tokenizer is required by this ABI.
E2E result text is saved exactly as returned by the reference detokenizer.
